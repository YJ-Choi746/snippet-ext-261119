# 내 문장 모음 (snippet-ext)

웹페이지에서 마음에 드는 **문장을 드래그하거나 그림 위에서 우클릭**해 모아 두고, 카드를 눌러 바로 복사하는 크롬 확장 프로그램이에요.

- Manifest V3 · 외부 라이브러리 없음 · 바깥 서버로 데이터를 보내지 않음
- 권한은 `contextMenus`(우클릭 메뉴), `storage`(내 크롬 안 저장) 두 개뿐 — 사이트 내용을 읽는 권한은 쓰지 않아요
- 최대 50개까지 내 크롬 안(`chrome.storage.local`)에 저장

## 기능
- 드래그 → 우클릭 **“ 내 문장 모음에 저장**, 그림 위 우클릭 → **이미지 저장**
- 저장하면 툴바 아이콘에 개수 배지 (45개부터 주황, 50개 FULL, 중복은 ✓)
- 팝업: 카드를 누르면 복사 (굵게·기울임·밑줄 서식도 함께), 그림은 주소 복사
- 주제 자동 추천과 주제 계열색, [전체·글·그림] 보기, 주제 필터, 검색(찾은 글자 칠하기)
- 편집: 굵게·기울임·밑줄, 메모, 주제 직접 입력(고친 주제를 배워 다음 추천에 반영), 그림 자르기
- 카드를 끌어서 순서 바꾸기, 색상 테마 5종
- ⤓ 백업(파일로 저장) · ⤒ 불러오기, 지운 카드 6초 안에 되돌리기

## 설치
1. 이 저장소를 내려받아 압축을 풀어요 (`Code → Download ZIP`, 또는 Releases 의 zip)
2. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → `manifest.json` 이 있는 폴더 선택
4. 툴바의 퍼즐 아이콘 → "내 문장 모음" 📌 고정

## 파일
| 파일 | 하는 일 |
|---|---|
| `manifest.json` | 확장 설정 (버전, 권한 2개) |
| `background.js` | 우클릭 메뉴, 저장, 배지, 툴바 아이콘 그리기 |
| `popup.html` | 팝업 화면 모양 |
| `popup.js` | 카드·복사·편집·검색·필터·순서·테마·백업·되돌리기 |
| `icons/icon128.png` | 확장 아이콘 (128×128) |

## 개인정보
자세한 내용은 [개인정보처리방침(PRIVACY.md)](PRIVACY.md)을 확인해 주세요.

- 저장한 문장·그림 주소·메모는 내 크롬 안에만 있고, 확장 프로그램이 바깥으로 보내지 않아요.
- 단, 그림 카드의 미리보기는 그 그림이 있던 원래 사이트에서 불러와요 (그 사이트는 그림을 다시 불러온 사실을 알 수 있어요).
